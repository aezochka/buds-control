# Buds Control

Приложение для управления TWS-наушниками на протоколе OPPO / realme / OnePlus.
Замена realme Link: без аккаунта, без рекламы, без телеметрии.

## Что умеет

**По протоколу гарнитуры** (Bluetooth Classic SPP, кадры `0xAA`):

- Заряд левого, правого наушника и кейса
- Шумоподавление: выкл / шумодав / прозрачность, переключается по кругу
- Игровой режим низкой задержки
- Эквалайзер прямо в наушниках — кривая уходит командой `0x0418`
- Жесты: отдельно для левого и правого, действие выбирается из списка
- Версия прошивки
- Поиск наушников звуковым сигналом
- Пространственный звук и подключение к двум устройствам

**Набор функций спрашивается у самой гарнитуры.** При подключении уходит запрос
возможностей (`0x0100`), устройство отвечает битовой маской. Так же это делает
вендорское приложение — поэтому у модели с ANC кнопки появляются сами, без правок
кода. Функция скрывается только когда опрос завершён и устройство о ней не
сообщило: пока идёт handshake, ничего не пропадает.

**Каталог моделей** — 33 модели с полным списком функций, поиск по модели и по
названию функции. Данные перенесены из конфигов realme Link.

**Системными средствами Android:**

- Эквалайзер как запасной путь: применяется к выводу телефона
- Лимит громкости — держится, даже если громкость поднять кнопками
- Таймер сна со своим временем, обратным отсчётом и уведомлением

**Интерфейс:**

- Material 3 Expressive: пружинная физика, морф форм, без системного ripple
- 12 акцентов темы плюс свой цвет по RGB
- Фото наушников подбирается автоматически по имени Bluetooth-устройства,
  фон вырезается — работает для любой модели, не только realme
- Индикаторы заряда ставятся рядом с наушниками на фото: положение считается
  анализом самой картинки, вручную можно поправить и изменить размер
- Несколько профилей наушников, порядок меняется перетаскиванием
- 8 языков, переключаются мгновенно
- Звуковые щелчки и вибро на действия, отключаются в настройках
- Обновление одной строкой в настройках: уже скачанный APK не качается заново,
  прерванная загрузка продолжается по `Range`
- Отчёт о сбое: стектрейс сохраняется и копируется одной кнопкой

## Установка

Готовый подписанный APK — в [релизах](../../releases/latest).

Подпись постоянная, поэтому обновления ставятся поверх без удаления.
Внутри приложения: **Настройки → Обновление**.

## Сборка

Только через GitHub Actions — воркфлоу `.github/workflows/build.yml` собирает
debug и release, подписывает и выкладывает артефакт.

Локально, если есть Android SDK и JDK 17:

```bash
./gradlew :app:assembleRelease
```

Ключ подписи лежит в репозитории (`buds-release.jks`) — это личный проект,
не для публикации в Play.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN` | связь с гарнитурой и поиск устройств |
| `INTERNET` | автоподбор фото наушников и проверка обновлений |
| `POST_NOTIFICATIONS` | уведомление таймера сна |
| `MODIFY_AUDIO_SETTINGS` | системный эквалайзер |
| `REQUEST_INSTALL_PACKAGES` | установка обновления из приложения |
| `VIBRATE` | отклик при нажатии |

Микрофон, геолокация и доступ к файлам **не запрашиваются**.

## Протокол

Кадры с префиксом `0xAA` поверх SPP/RFCOMM. Базовая часть — открытая реализация
из [Gadgetbridge](https://codeberg.org/Freeyourgadget/Gadgetbridge)
(`service/devices/oppo`).

Команды эквалайзера и таблица возможностей сняты декомпиляцией realme Link
(jadx), модуль `realmeHeadset.apk`:

| Что | Код |
|---|---|
| Возможности модели | `0x0100`, ответ `0x8100` |
| Кривая эквалайзера | `0x0418` |
| Включение эквалайзера | `0x0406` |
| Шумоподавление | `0x0404` |
| Поиск устройства | `0x0400` |

Формат кадра эквалайзера:

```
[0] action (0 = записать, 5 = запросить)
[1] minDb  [2] maxDb  [3] eqId  [4] длина имени
    количество полос, далее на полосу: частота (2 байта LE) + усиление (1 байт, signed)
```

Частоты передаются явно, поэтому кривая произвольная, а не фиксированные полосы.

### Что известно, но не сделано

- **Усиление громкости и пресеты звука** (Bass Boost+, Баланс, Чёткий) на T110
  идут через другой протокол — `wm/spplibrary`, атрибут `26`. У него шифрованный
  handshake, поэтому вслепую не реализовано.
- **Названия моделей** в APK realme Link отсутствуют: они приходят с сервера
  `client-uc.heytapmobi.com`, API закрыто и подписывает запросы. В каталоге
  честно показывается `modelId`.
- **Дельта-обновления** для sideload невозможны: Android ставит только целый
  подписанный APK. Сделана докачка и переиспользование скачанного файла.

## Проверено на

realme Buds T110. Другая модель на этом протоколе должна работать без правок
кода — набор функций определяется опросом устройства.

Что подтверждено железом: подключение, заряд, игровой режим, жесты, прошивка.
Эквалайзер в наушниках и ANC реализованы по вендорскому протоколу, но на модели
без этих функций проверить их нельзя — приложение помечает функцию рабочей
только после ответа гарнитуры.
