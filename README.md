# Buds Control

Приложение для управления TWS-гарнитурами на протоколе OPPO / realme / OnePlus (BBK),
в стиле Material Design 3 (Material You), интерфейс на русском.

## Главная идея

Набор доступных настроек **определяется живым опросом самой гарнитуры**, а не
списком моделей. Приложение отправляет по одному запросу на каждую функцию;
устройство, которое функцию не умеет, просто не отвечает. Поэтому:

- у realme Buds T110 не будет фейкового переключателя ANC — его там нет физически;
- у Buds Air 5 Pro появятся и ANC, и LDAC, и multipoint;
- незнакомая модель всё равно заработает — ей достаётся полный опрос.

На экране «Наушники» видно итог: какие функции подтвердились, а какие нет.

## Транспорт

Bluetooth Classic SPP (RFCOMM, UUID `00001101-0000-1000-8000-00805F9B34FB`).
Кадр протокола (little-endian):

```
AA | len(all-2) | 00 | 00 | cmd:u16 | seq:u8 | payloadLen:u16 | payload
```

Коды команд взяты из открытой реализации Gadgetbridge (AGPL-3.0), раздел `oppo`.

## Сборка

APK собирается в GitHub Actions на каждый push в `main`, артефакт `BudsControl-apk`.
Локально:

```bash
./gradlew :app:assembleRelease
```

## Что поддерживается

| Функция | Как определяется |
|---|---|
| Заряд (левый / правый / кейс) | ответ на `0x0106`, число ячеек из payload |
| Прошивка | ответ на `0x0105` |
| ANC + режимы | ответ на `0x010C` |
| Перебор ANC касанием | ответ на `0x010C` с типом `0x02` |
| Игровой режим, multipoint, LDAC | ответ на `0x010D` по каждому типу отдельно |
| Настройка жестов | ответ на `0x0108`, слоты из payload |
| Поиск наушников | `0x0400` |
